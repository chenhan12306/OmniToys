桌面栅栏 (Desktop Fences)

微软 Windows 桌面图标与文件分区整理利器（1:1 复刻 Stardock Fences）。自动在桌面上生成半透明磨砂玻璃容器，支持双击折叠卷起、文件夹传送门与一键隐藏桌面。
